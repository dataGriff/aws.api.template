Todo API (1.0.0)

Download OpenAPI specification:

URL: https://github.com/dataGriff/aws.api.template License: MIT

A multi-tenant Todo API — the worked example for the AWS API template.

Every request is authenticated with a Cognito-issued JWT. Todos are scoped to the caller's tenant and user (from the token's sub and custom:tenant_id claims); the API never accepts a client-supplied owner. This contract is the single source of truth: server types, gateway request validation, the consumer SDK, the mock server, the .http collection, and the reference docs are all generated from it.
